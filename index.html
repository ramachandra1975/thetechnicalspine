Recommended Build Sequence

Initialise Domain 9 immediately — even while building Domains 1–8. The sequence allows progressive publishing so partially-complete work is always navigable.

1
SD54 — GitHub Repository Modules
Establish the code spine first. Everything else is built on top of this. Audit all repos at ramachandra1975 and create the org-level README.
2
SD55 — Subdomain CMS Architecture
Navigation must exist before content is published. Audit all 12 subdomains, design the shared navigation component, and build the shell.
3
SD56 — Reference Site Harvesting
Can be done in parallel with D1–8 builds. Generates immediate value. Compile all 60+ URLs into the tagged master index JSON.
4
SD57 — Cross-Domain Knowledge Graph
Seed with all 54 nodes immediately. Add cross-domain edges progressively as each domain completes. The three CSP edges go in first.
5
SD58 — Multiverse Knowledge Base Indexing
Build the schema early; populate progressively. The index grows as domains complete. Choose Lunr.js for fully static; Algolia for hosted search.
6
SD59 — Unified Theory Hub
The culmination. Build last, once the knowledge graph and index are sufficiently populated. This is the grand convergence document.
